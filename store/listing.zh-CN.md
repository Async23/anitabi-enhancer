## 简短说明

为动画巡礼地图显示作品名称，在地图内快捷调整展示、手动控制作品列表、圆点、头像、名称和地点缩略图。非官方扩展。

## 详细说明

本扩展已开源，欢迎反馈问题和参与改进。
GitHub 源码：https://github.com/Async23/anitabi-enhancer

浏览 Anitabi 动画巡礼地图时，直接看清作品名称，并按需要调整地图上的信息。

主要功能：
• 作品栏显示头像、名称与点位数，支持中文名或原名优先。
• 在顶部横排与左侧列表之间切换；横排支持鼠标滚轮左右浏览。
• 圆角方形头像、完整名称悬停提示和键盘操作，让作品更易辨认和选择。
• 通过眼睛菜单分别控制彩色圆点、作品头像、地图作品名称、地点缩略图和区域作品列表。
• 手动收起作品列表后，移动或缩放地图不会自动展开；已有筛选会保留，并提供清除入口。
• 在地图内调整设置，立即生效；界面跟随系统明暗。

使用方式：安装后打开 https://www.anitabi.cn/map，点击地图右侧的滑杆按钮调整作品栏，点击眼睛按钮控制各类内容。已有地图页面首次安装后可刷新一次。

名称、语言和位置保存在本机。眼睛菜单开关只影响当前页面，刷新后恢复显示。远景作品列表根据页面已加载的点位统计，默认最多展示 20 部并保留已选作品；它不是整个区域的全量数据库。

扩展在浏览器内处理地图内容和显示偏好，不向开发者上传浏览内容，不包含广告或使用统计。作品图片由原网站使用的图片服务加载。

本扩展为独立开发的非官方项目，与 Anitabi 官方无隶属关系。作品图像、地图和地标数据的权利归各自权利人。本项目代码以 MIT 许可证开源。

## 单一用途

改善 Anitabi 动画巡礼地图的作品识别与信息展示：显示作品名称和区域作品列表，并提供同一地图中的布局、筛选提示和各类标记显隐控制。

## 权限说明

### storage

在 chrome.storage.local 保存用户选择的作品名称显示方式、布局位置和名称语言；在 chrome.storage.session 临时保存待打开设置的地图标签页 ID。不会使用云同步，不存储浏览历史或作品数据库。

### scripting

在扩展更新、重新加载或用户点击工具栏按钮时，将安装包内的脚本注入受支持的 Anitabi 地图，恢复设置同步并打开地图内设置。只执行扩展包内脚本，不执行远程代码。

### 网站权限

仅访问 anitabi.cn、www.anitabi.cn、w.anitabi.cn 和 hk.anitabi.cn 的 HTTPS 页面。这些地址是本扩展支持的地图入口，用于读取地图已加载的作品、点位和当前筛选，增强地图界面，并查找当前窗口内已打开的地图。无需其他网站或所有标签页权限。

### 远程代码

选择「否」。JavaScript 和 CSS 随扩展包发布；只读取网站运行时的数据及加载图片，不将下载内容作为扩展代码执行。

## 数据处理申报依据

与 PRIVACY.md 保持一致：扩展在本机处理网站内容（作品、点位、当前地图范围）、用户活动（当前显示选择与筛选）和受支持地图的当前标签页地址，用于用户可见的增强功能。不要将「未上传到开发者服务器」写成「完全不处理数据」。按后台对网站内容、用户活动和浏览活动的字段定义披露这些用途；不读取历史记录数据库，不收集密码、通信、财务、健康或设备定位信息。

数据不出售、不用于无关目的或信用评估。图片请求直接发往原网站的图片服务，不发往扩展开发者的服务器。详细保存与清除规则见隐私政策。

## 审核复现步骤

不需要账号或测试凭据。

1. 安装扩展，打开 https://www.anitabi.cn/map?c=141.356%2C43.0605&z=13.2，等待地图和作品加载。
2. 确认作品栏显示名称与数量；点击右侧滑杆按钮，将「展示位置」切为「左侧列表」，观察即时变化。
3. 点击眼睛按钮，分别关闭彩色圆点、作品头像、地图作品名称、地点缩略图，观察它们独立隐藏，底图仍保留。
4. 选择一部作品，关闭「区域作品列表」，观察筛选提示。移动和缩放地图，列表保持隐藏；点击「清除筛选」，筛选解除但列表仍不展开。
5. 重新打开「区域作品列表」，确认内容按当前地图范围更新。刷新页面，临时显隐恢复开启，保存的位置和语言保持。
6. 点击浏览器工具栏扩展图标，确认打开的是同一地图设置面板。

网站加载需要网络。底图、作品图像和地标数据由 Anitabi 及其服务提供方提供。
