# 安装与使用

## 安装

1. 在 Chrome 地址栏输入 `chrome://extensions`。
2. 打开页面右上角的「开发者模式」。
3. 点击「加载已解压的扩展程序」，选择本项目的 `extension` 文件夹；该文件夹里应直接包含 `manifest.json`。
4. 刷新已经打开的 Anitabi 地图页面。

也可以从 [GitHub Releases](https://github.com/Async23/anitabi-enhancer/releases) 下载 ZIP，或使用 `npm run build` 自行生成。解压后，选择直接包含 `manifest.json` 的文件夹。ZIP 不能直接拖进 Chrome 安装。

## 使用

作品栏会显示「头像＋名称＋点位数」。拖动地图后，列表随当前地图范围更新。

点击地图右侧的滑杆图标（悬停提示「作品设置」），即可直接调整显示方式、展示位置和名称语言。入口与地图原生按钮使用相同的方形尺寸和圆角。名称、位置和语言使用一键切换按钮；点击面板外部、按 Esc 或点击「收起」关闭面板。

设置只保留地图内这一处。点击浏览器工具栏中的扩展图标会打开同一个面板，不再弹出另一套设置。在其他网页点击时，会切换到当前窗口已打开的 Anitabi 地图；没有地图时新建地图标签页并打开设置。已有设置会保留，多个地图标签页之间实时同步。

点击右侧的眼睛图标展开「地图标记」菜单，分别打开或关闭「彩色圆点」「作品头像」「地图作品名称」「地点缩略图」「区域作品列表」。开关打开表示显示，修改立即生效；可以只看名称、只看头像，或把这五类内容全部隐藏。有隐藏项时眼睛按钮变蓝，全部隐藏时显示划线眼睛。地点缩略图开关控制搜索框下方的地点预览卡片；隐藏后，左侧作品列表会自动上移利用空位。普通地图信息和作品筛选不受影响。打开缩略图开关后，仍沿用网站的显示条件（通常从 12 级开始）。

标记的隐藏状态只限当前页面，关闭菜单、拖动、缩放及重新加载扩展后仍保持，刷新地图后恢复显示；不更改作品筛选，也不保存为长期偏好。点击菜单外部或按 Esc 收起菜单，菜单与作品设置面板不会同时展开。

在「展示位置」中切换：

- 顶部横排：默认布局。作品较多时出现左右浏览按钮，悬停提示还有多少项，到达边界时变灰；鼠标滚轮向下可向右浏览，向上可向左浏览，也支持触控板横向滑动。滚动条位于卡片下方的预留空间内。
- 左侧列表（缩略图下方）：作品纵向排列，滚轮上下浏览；紧凑模式会排列成图标网格。列表跟随缩略图高度调整位置，并避开公告和底部地图控件，滚动条位于卡片右侧的预留空间内。

左侧列表在还有内容的方向显示柔和渐隐，让被截断的卡片自然融入地图；到达顶部或底部时，对应一侧恢复完整显示。内容不足一屏时不渐隐，右侧滚动条始终保持清晰。

切换即时生效，保留当前作品筛选，并记住位置选择。窗口过矮、左侧无法容纳至少两行作品时，临时恢复顶部布局；空间恢复后自动回到左侧。

更改设置无需刷新地图。重新加载扩展后，会自动恢复已打开地图的设置同步和页面入口；切回地图标签页时也会尝试重连。如果工具栏图标出现「!」，悬停可查看提示；稍后再次点击，仍无响应时刷新对应地图页面重试。

鼠标在作品栏内滚动不会缩放地图，即使已经到达边界；移到地图上后恢复网站原有的滚轮操作。

长名称最多显示两行，悬停可查看完整的中文名、原名和点位数量。作品图片可能来自专用方形头像，也可能来自横版或竖版封面；头像统一显示为圆角方形，保持比例并居中裁切，彩色描边贴合圆角。常驻名称模式下大小为 34×34 CSS 像素，紧凑模式保留网站的头像尺寸。

窄窗口中公告占据顶部空间时，顶部作品栏会移到公告下方；收起公告后自动恢复位置。

点击作品沿用原网站的多选筛选；也可用 Tab 聚焦作品，再按 Enter 或空格切换选择。网站原有列表直接使用其点位数量；低于 12 级的补充列表从地图已加载的点位中去重统计。

在「作品设置」中选择列表中的名称显示方式，以及中文名或原名优先。地图上的作品文字由眼睛菜单的「地图作品名称」独立控制。界面自动跟随系统明暗，不再提供主题切换按钮，旧版手动主题选择不再生效。操作面板内的滚轮和键盘不会误操作地图；面板过高时可在内部滚动。

## 区域作品列表

眼睛菜单中的「区域作品列表」控制作品卡片整栏的显示。默认开启，关闭时整栏收起，并暂停补充列表的统计；拖动、放大或缩小地图不会改变这个开关。重新打开时按当前地图范围更新，地图位置和缩放保持不变。与其他眼睛菜单开关一致，这个选择仅限当前页面，刷新后恢复开启。

关闭列表不会清除筛选。有已选作品时，搜索框或地点缩略图下方显示「已筛选 N 部作品」：点击文字重新展开列表，点击「清除筛选」恢复全部作品；清除筛选不会自动打开列表。

远景列表从已加载点位中去重统计，默认最多显示 20 部，按点位数排序；已选作品优先保留，超过 20 部时也保留全部已选作品，方便取消。达到数量限制时显示提示。这些结果代表当前已加载数据，不保证是整个区域的全量作品。加载中、空区域和暂时读取失败分别有文字提示。

12 级仅作为扩展补充列表和原站列表的内部交接点，不再是用户设置。地点缩略图仍按网站的显示条件出现，独立受缩略图开关控制。进入单部作品详情时沿用网站布局，返回地图后恢复作品列表的开关状态。

0.7.0 起移除数字阈值和「恢复 12」。升级时已经打开的页面沿用当时列表的显示或隐藏状态，筛选保留；新页面和刷新后的页面默认开启。旧阈值不再生效，也不会自动转换成永久隐藏偏好。

## 适用范围与限制

- 支持 `anitabi.cn`、`www.anitabi.cn`、`w.anitabi.cn` 和 `hk.anitabi.cn` 的地图界面。
- 作品列表手动显隐；远景统计范围限于页面已加载的数据。
- 优先使用页面已有名称；没有中文名时回退到原名。
- 不能准确识别的自定义图标不添加作品名称。网站的数据结构或界面更新后，扩展可能需要适配。
- 关闭或移除扩展后，刷新地图即可恢复原网站界面。

## 更新本地安装的扩展

使用同一 `extension` 文件夹时，在 `chrome://extensions` 找到「Anitabi 增强」，点击卡片上的重新加载按钮。已打开地图的设置入口和同步会自动恢复。使用 ZIP 安装时，先把新版本解压到原来加载的目录，再执行上述步骤。如果更新还包含其他页面功能或样式调整，需要刷新地图加载这些新代码。

## 数据与权限

扩展申请设置存储权限，以及仅在上述四个 Anitabi 域名执行页面脚本的权限，用于增强界面和在重新加载扩展后恢复设置同步。它读取页面中已加载的作品和点位信息，远景作品图标使用网站提供的图片地址；不额外下载地标库，不上传浏览记录，不包含远程执行代码，也不会修改 Anitabi 服务器上的数据。

本扩展与 Anitabi 官方无隶属关系。作品图像、名称及地标信息的权利和使用要求以原网站为准。

完整的数据处理、权限用途与删除方式见[隐私说明](../PRIVACY.md)，素材归属见 [NOTICE](../NOTICE.md)。
