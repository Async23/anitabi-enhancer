# Anitabi 增强

面向 [Anitabi 动画巡礼地图](https://www.anitabi.cn/map) 的非官方 Chrome 扩展，让作品图标同时显示名称与点位数，支持顶部横排或左侧列表。

- [安装与使用](docs/usage.md)
- [开发与验证](docs/development.md)
- [可直接加载的扩展目录](extension/)
- [下载发布版本](https://github.com/Async23/anitabi-enhancer/releases)
- [隐私说明](PRIVACY.md)
- [问题反馈](https://github.com/Async23/anitabi-enhancer/issues)

扩展在浏览器本地增强界面，作品和地标数据仍由 Anitabi 提供。

项目代码采用 [MIT 许可证](LICENSE)。第三方网站内容与素材的归属见 [NOTICE](NOTICE.md)。本项目与 Anitabi 官方无隶属关系。
